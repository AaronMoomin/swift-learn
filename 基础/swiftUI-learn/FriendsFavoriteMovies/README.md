# Friend's Favorite Movies: Create, update, and delete data

Extend the Friends’ Favorite Movies project from [Navigate sample data](https://developer.apple.com/tutorials/develop-in-swift/navigate-sample-data) to let people create, edit, and delete friends and movies.

Start by adding detail views so that people can edit friends and movies. Then, update the list views to let people add and delete items. Finally, fine-tune the detail views and present them in sheet interfaces for adding new friends and movies.

## Overview

These resources are associated with the [Create, update, and delete data](https://developer.apple.com/tutorials/develop-in-swift/create-update-and-delete-data) tutorial. This is part of the [Data Modeling](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-data-modeling) tutorials from [Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) by Apple.

## Using these resources

Follow the tutorial instructions in section one of [Create, update, and delete data](https://developer.apple.com/tutorials/develop-in-swift/create-update-and-delete-data) to use these resources within the Xcode app.
